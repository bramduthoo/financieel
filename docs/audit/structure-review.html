What it is

budgeting-page-plan.md, pdf-import-plan.md, kbc-adapter-spec.md, kbc-csv-import-background.md, encryption-with-key-plan.md, backup-restore-feature-plan.md — 1,553 lines of feature-specific specification currently in the repository root.

Why it may go

After the Session 3 cleanup the root holds 11 markdown files. Five are entry points; six only matter once you are already deep in a feature. Moving the six leaves a root where every markdown file is somewhere you would actually start.

docs/archive/ and docs/audit/ already establish that docs/ is where non-entry documentation lives — these six simply never moved there.

Risk if actioned

Low, but not zero. Four of the six are cited from inside working source code as authoritative specs:
